# Personal site: Md Tasbeer Ahmed

Plain HTML, CSS and JavaScript. No build step.

## Put it on GitHub Pages
1. On GitHub, create a **public** repository named `YOUR-USERNAME.github.io`.
2. Upload everything in this folder (index.html, style.css, sim.js, img/, files/) to the repository root.
3. Open Settings > Pages, set Source to "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
4. After a minute the site is live at `https://YOUR-USERNAME.github.io`.

## Update it
- Replace a PDF in `files/` with a new one of the same name.
- Edit text in `index.html`.
